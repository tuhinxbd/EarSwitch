> 💡 **EarSwitch** gives you instant, granular control over your sound devices and running apps without opening cumbersome system menus. Built exclusively for speed, privacy, and seamless Windows 11 aesthetics.

---

### ✨ Key Features

- 🎨 **Fluent 2 Modern UI** — Crafted with native Windows 11 design principles, dark/light theme support, and smooth, flicker-free animations.
- 🎛️ **Per-Application Volume Control** — Independently adjust volume and mute states for any active app or game with instant visual response.
- 🔄 **Quick Output Switching** — Switch default audio playback and communication devices directly from the flyout or tray.
- 🎭 **Customizable Tray Icons** — Choose from multiple stylish icon themes (*Headphones, Audio Waves, Treble Clef, Saxophone, Dynamic indicator*).
- ⚡ **Global Hotkeys** — Assign custom keyboard shortcuts to adjust sound levels on the fly.
- 🛡️ **100% Local & Private** — No telemetry tracking, no analytics, and zero network transmission.
